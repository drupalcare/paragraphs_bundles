# Paragraph Bundle Block Content

Paragraph Bundle Block Content sub-module for [Paragraphs
Bundles](https://www.drupal.org/project/paragraphs_bundles).

## Description

Embed custom block content inside a paragraph.

Uses the parent `paragraph--default.html.twig` template (Track A — no custom
Twig).

## Requirements

- Drupal 11.3+ or 12
- PHP 8.3+
- `paragraphs_bundles` (parent module)
