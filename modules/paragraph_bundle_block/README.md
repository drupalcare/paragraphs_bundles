# Paragraph Bundle Block

Paragraph Bundle Block sub-module for [Paragraphs
Bundles](https://www.drupal.org/project/paragraphs_bundles).

## Description

Embed a Drupal block inside a paragraph with Display tab styling.

Uses the parent `paragraph--default.html.twig` template (Track A — no custom
Twig).

## Requirements

- Drupal 11.3+ or 12
- PHP 8.3+
- `paragraphs_bundles` (parent module)
